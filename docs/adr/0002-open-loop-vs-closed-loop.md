# ADR 0002: 开环回放与闭环断言分离

- 状态：接受
- 日期：2026-09-11

## 决定

每个断言声明 `requires_mode: open_loop | closed_loop`。run 记录自己的 `mode`。模式不匹配的断言结果为 `skipped`，不把 suite 打红。报告必须单独列出 skipped。

开环（`python-policy`）只断言动作偏差、限位、平滑、时延（只报告）、置信度。抓取成功、碰撞、到达目标只在闭环（仿真或真机节点）上判定。

## 理由

给定录制观测再取策略动作，看不到夹爪状态或碰撞。把闭环断言挂在开环 target 上会得到假红或假绿。开环回归仍然有价值：新权重是否还产出接近当时的动作。它不等于「机器人还会成功」。

## 后果

`gate` 与 HTML 报告区分两种证据。不宣称开环 replay 与真机等价。M3 用仿真补闭环统计。
